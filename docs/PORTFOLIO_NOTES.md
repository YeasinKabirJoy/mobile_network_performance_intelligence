# Portfolio Presentation Notes

## One-sentence project statement

I built a reproducible SQLite and geospatial analytics pipeline that converts verified public mobile-performance tiles into explainable regional comparisons and investigation priorities without overstating them as network faults.

## Suggested five-slide sequence

1. Business question, users, and strict interpretation boundary.
2. Source, spatial extraction, tile-quarter grain, and validation evidence.
3. SQL/EDA findings with weighted-versus-unweighted explanation.
4. Transparent priority score, sensitivity, and real-area trace.
5. BI handoffs, cross-tool reconciliation, recommendations, and necessary follow-up evidence.

## Honest portfolio language

- Say "public aggregated measurement tiles," not towers or subscribers.
- Say "test-weighted reconstruction," not national subscriber speed.
- Say "priority for investigation," not detected fault.
- Say "BI-ready, reconciled dashboard specifications" until native PBIX/TWBX files and screenshots pass their manual checkpoints.
- State that SQLite replaced the guide's recommended DuckDB by explicit learner choice and document the tradeoff.
