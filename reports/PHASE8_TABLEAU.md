# Phase 8 Tableau Geographic Exploration

## What was built

- A 15,956-row flat tile-quarter CSV designed for Tableau geographic exploration.
- A complete field dictionary including roles, types, meanings, and cautions.
- Explicit Tableau calculated fields matching SQLite and Power BI denominator semantics.
- Six worksheet specifications, including an honest single-quarter treatment.
- Three linked-filter/highlight action definitions.
- A real selected-tile trace and regional KPI contribution.
- A static map-led build reference using actual values, clearly labeled as not a Tableau screenshot.
- Local packaging, refresh, Tableau Public licensing/privacy guidance, and acceptance checks.

## Verified result

The export has 15,956 rows and 24 columns. Eighteen comparisons across the All Bangladesh, Dhaka, and Rajshani states pass. Tile `1320222021021031` is traced into Dhaka's weighted-download calculation and is highlighted in the build reference.
